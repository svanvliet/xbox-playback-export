# Xbox Playback Export

A local-first agent skill and plugin project for exporting personalized Xbox
Playback presentations as videos without playback controls.

## Status

Initial development. There is no installable release yet. The export approach has
been demonstrated locally on macOS; Windows support and reusable acquisition
still need validation.

The goal is one shared export implementation with thin integration packaging for
GitHub Copilot, Claude Code, and supported ChatGPT execution environments.

## Privacy and project boundaries

- Sign in directly to Xbox; never provide account passwords or tokens to this project.
- Process personalized playback data locally.
- Do not commit personalized payloads, browser profiles, recordings, or diagnostics.
- Xbox application bundles, fonts, images, and music are not distributed here.
- Downloading public assets does not grant redistribution rights.

This is an independent project, not an official Xbox product.
